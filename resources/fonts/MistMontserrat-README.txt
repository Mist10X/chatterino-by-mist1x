Montserrat SemiBold is a static wght=600 instance of the official Google Fonts Montserrat variable font:
https://github.com/google/fonts/blob/main/ofl/montserrat/Montserrat%5Bwght%5D.ttf
Family names were changed to Mist Montserrat for app-local isolation, consistently with the bundled Regular and Bold fonts.
License: SIL Open Font License 1.1 (OFL.txt).

Bundled so the Mist Montserrat chat font works without installing it (older profiles that name "Archive Montserrat" are moved to it). No Windows font installation.
