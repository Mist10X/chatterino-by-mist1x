# Локализация интерфейса Leafyrino

Язык выбирается в **Настройки → Основные → Интерфейс → Язык (нужен перезапуск)**.
В английском интерфейсе: **Settings → General → Interface → Language (requires restart)**.
Варианты: **Русский** и **English**. После выбора нужно штатно перезапустить Leafyrino.
Закрытие настроек кнопкой «Отмена» восстанавливает предыдущий выбор, как и остальные настройки.

Настройка `/appearance/uiLanguage` сохраняет стабильный код `ru` или `en`.
Значение по умолчанию — `ru`; неподдерживаемый код использует английский интерфейс.
Динамическая смена уже созданных окон не реализована: подпись прямо сообщает о перезапуске.

## Граница перевода

`src/common/UiLanguage.*` переводит только явно обозначенный интерфейсный текст.
Нет прохода по всем виджетам с заменой произвольных строк. Имена пользователей,
каналов, эмоутов, сообщения, пользовательские команды, пути и сетевые payload
не отправляются переводчику автоматически. Шаблон переводится **до** `.arg(...)`.

`UiComboBox` хранит исходные значения вариантов отдельно от отображаемых подписей.
Перечисления, индексы, коды языков и имена действий горячих клавиш остаются прежними.
Названия пользовательских тем также не переводятся.

Перевод не меняет `QLocale::setDefault`, шрифт приложения, семейство/размер шрифта чата
или масштаб. Встроен стандартный русский каталог `qtbase_ru.qm` из используемого Qt 6.9.3
для стандартных Qt-кнопок и меню; это ресурс Qt с действующими для Qt условиями лицензии.

## Каталоги

- `resources/i18n/ru.json`: английский интерфейсный текст → русский;
- `resources/i18n/en.json`: ранее русский интерфейсный текст → английский;
- `extra-ru.json`: дополнения и исправления уже проверенных переводов;
- `build_catalog.py`: сборка каталогов и проверка подстановок, ссылок и переменных команд;
- `Preview.cpp`: изолированная проверка настоящих виджетов в обоих языках.

Нумерованные TSV ссылаются на **зафиксированные** inventory JSON. Не пересоздавайте
эти JSON после изменения исходников: номера потеряют соответствие. Для новой строки
добавьте явный `uiText(...)` в месте показа и перевод в `extra-ru.json`, затем выполните
`build_catalog.py`. Служебные скрипты `apply_*.py` использовались при первоначальной миграции;
они не являются частью сборки, их повторное массовое применение требует проверки diff.

## Проверки

Сборка с `LEAFYRINO_LOCALIZATION_TESTS=ON` создаёт `Leafyrino-localization-tests`.
Fixture работает только из `D:/devtools`, без загрузки аккаунтов и запуска сетевых провайдеров.
Он создаёт временные настройки, проверяет выбор языка, исходные значения вариантов,
формулы фильтра, неизменность шрифтов/locale и сохраняет PNG собственных виджетов
в `offscreen`-режиме. Это не снимки рабочего стола и не тест рабочего профиля.

После изменения `Settings.hpp` нужна согласованная пересборка всех зависимых объектов.
Проверяйте непустой вывод Ninja `-t deps` и совпадение `msvc_deps_prefix` с реальным
выводом `/showIncludes`: несогласованная локаль MSVC может скрыть зависимости заголовков.

Внешние страницы входа, Windows-диалоги, сообщения серверов, тексты плагинов и контент
чата не обещают соответствовать выбранному языку Leafyrino.
